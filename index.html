クラネイ — KCNA-JP 対策

クラネイ (クラウドネイティブの略) は、KCNA-JP (Kubernetes and Cloud Native Associate 日本語版) の対策のための、個人が作った非公式の学習サイトです。 kubectl コマンドや YAML・Dockerfile の穴埋めと 4 択を、週ごとのレッスンで解きます。間違えた問題は、選んだものがなぜ違うかと解説・出典を出します。

学べること

  • Kubernetes Fundamentals: コンテナの基礎、クラスタの構成、ワークロード、管理とスケジューリング
  • Container Orchestration: ネットワーク、セキュリティ、ストレージ、障害対応
  • Cloud Native Application Delivery: GitOps、Helm、Kustomize
  • Cloud Native Architecture: 観測、オートスケール、CNCF のエコシステム

進み具合はブラウザの localStorage にだけ残り、サーバーには送りません。表示には JavaScript を使います。
